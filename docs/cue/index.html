PCのoperator窓は左にスライド、右にアプリ。approverは独立認証の別窓。両方で同じ本番用LIVE請求を選ぶ。開始時はメール受付済み・未処理。本人がRun invoice agentを押し、処理後にCAD4,800、登録0042・要求7719の不一致と保留が表示される。

Quick Q&A

What does MongoDB do?Atlas stores people, suppliers, approvals, state, and evidence. The server checks these before payment.

Can the agent approve itself?No. Approval needs a separate signed-in person. Direct API calls face the same checks.

Is this a real payment?The model and Atlas are real. Supplier confirmation is synthetic. Payment is simulated.

What if the response is lost?We keep the same payment ID and check it again. We have not tested every network failure.
